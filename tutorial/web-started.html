Web開発環境構築ガイド

1. Visual Studio Codeのインストール

Web開発で使用するコードエディタをインストールします。

  • Visual Studio Code公式サイトにアクセス（ダウンロードページ）
  • Windows用インストーラーをダウンロード
  • ダウンロードしたインストーラーを実行
  • インストール完了後、Visual Studio Codeを起動

2. 日本語化と拡張機能のインストール

Visual Studio Codeを使いやすくするための設定を行います。

  • 左側のExtensionsアイコンをクリック（または Ctrl+Shift+X）
  • 検索バーで「Japanese」と入力し、「Japanese Language Pack」をインストール
  • Visual Studio Codeを再起動して日本語化を適用
  • 同様に以下の拡張機能をインストール：
      • Live Server（HTMLファイルをブラウザで確認）
      • Auto Rename Tag（HTMLタグの編集補助）
      • HTML CSS Support（HTMLとCSSの入力補完）

3. 作業フォルダの準備

Web制作用のフォルダを作成します。

  • デスクトップなど分かりやすい場所に新しいフォルダを作成
  • Visual Studio Codeを開き、「ファイル」→「フォルダを開く」で作成したフォルダを選択
  • 以下のような構成でフォルダとファイルを作成： 
    project/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/

4. 動作確認

環境が正しく構築できているか確認します。

  • index.htmlに基本的なHTMLを記述
  • Live Serverを起動（右クリック→「Live Serverで開く」）
  • ブラウザが起動し、作成したページが表示されることを確認
