Web開発環境構築ガイド

1. Visual Studio Codeのインストール

Web開発で使用するコードエディタをインストールします。

  • Visual Studio Code公式サイトにアクセス（ダウンロードページ）

    •  自分のPCのOSにあったものをダウンロードしてください(ほとんどの人はWindowsだと思います)


  • ダウンロードしたインストーラーを実行

    •  同意をするをクリック→次へをクリック


     次へをクリック(保存先にこだわりがある場合はこのタイミングで指定してください)


     次へをクリック


     デスクトップ上にアイコンを作成するをクリックして次へをクリック


     インストールをクリック


     完了をクリック


    これでインストールは完了です。ここからは拡張機能を入れてVisualStudioCodeに追加で機能を加えていきます。

2. 日本語化と拡張機能のインストール

  • 左側のExtensionsアイコンをクリック（または Ctrl+Shift+X）
  • 検索バーで「Japanese」と入力し、「Japanese Language Pack」をインストール(Microsoftがリリースしているものをインストールしてください)
  • Visual Studio Codeを再起動して日本語化を適用
  • 同様に以下の拡張機能をインストール：
      • Live Server（HTMLファイルをブラウザで確認できる機能）
      • Auto Rename Tag（HTMLタグを自動で補完してくれる機能）
      • HTML CSS Support（HTMLとCSSの入力補完）

3. 作業フォルダの準備

Web制作用のフォルダを作成します。

  • デスクトップなど分かりやすい場所に新しいフォルダを作成
  • Visual Studio Codeを開き、「ファイル」→「フォルダを開く」で作成したフォルダを選択
  • 以下のような構成でフォルダとファイルを作成： 
    project/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/

     上の画像のようになればOKです

4. 動作確認

環境が正しく構築できているか確認します。試しに文字を表示してみましょう！

  • index.htmlに基本的なHTMLを記述
    • 
1<!DOCTYPE html>
2<html lang="ja">
3  <head>
4    <meta charset="UTF-8" />
5    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
6    <title>環境構築テスト</title>
7  </head>
8  <body>
9    <a>Hello, World!</a>
10  </body>
11</html>
  • Live Serverを起動

    •  右下の「Go Live」をクリック


  • ブラウザが自動で起動し文字だけのページが表示されたら環境構築は成功です！
