HTML基礎チュートリアル

1. HTMLとは

HTMLは、Webページの構造を定義するためのマークアップ言語です。

  • Webページの基本構造を作る
  • テキストや画像を配置する
  • リンクやフォームを作成する

2. 開発環境の準備

HTMLの編集に必要なテキストエディタをインストールします。

  • Visual Studio Codeをダウンロード（公式サイト）
  • 日本語化拡張機能をインストール
  • Live Serverプラグインをインストール

3. HTMLの基本構造

全てのHTMLファイルは以下の基本構造を持ちます：

<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>ページタイトル</title>
</head>
<body>
    <!-- ここにコンテンツを書きます -->
</body>
</html>

4. 基本的なタグ

よく使用するHTMLタグの例：

  • <h1> - 見出し
  • <p> - 段落
  • <a> - リンク
  • <img> - 画像
  • <ul> - 箇条書きリスト

5. 実践演習

以下の手順で簡単なWebページを作成してみましょう：

  1. 新しいフォルダを作成
  2. index.htmlファイルを作成
  3. 基本構造を記述
  4. コンテンツを追加
  5. Live Serverで確認
