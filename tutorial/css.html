CSS基礎チュートリアル

1. CSSとは

CSSは、Webページのスタイルやレイアウトを定義するためのスタイルシート言語です。

  • 色やフォントの設定
  • レイアウトの調整
  • アニメーションの作成

2. CSSの基本構文

CSSの基本的な書き方：

セレクタ {
    プロパティ: 値;
    プロパティ: 値;
}

例：

h1 {
    color: blue;
    font-size: 24px;
}

3. セレクタの種類

主なCSSセレクタ：

  • 要素 - 例：p, h1, div
  • .クラス名 - 例：.header, .button
  • #ID名 - 例：#main, #footer
  • 要素:hover - マウスホバー時
  • 親要素 > 子要素 - 直接の子要素

4. レイアウト

モダンなレイアウト手法：

  • Flexbox
    • 一次元のレイアウト
    • 要素の配置と整列
  • Grid
    • 二次元のレイアウト
    • 格子状の配置

5. レスポンシブデザイン

異なる画面サイズに対応するための技術：

@media screen and (max-width: 768px) {
    /* スマートフォン向けのスタイル */
    .container {
        width: 100%;
    }
}
