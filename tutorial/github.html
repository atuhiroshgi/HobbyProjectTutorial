GitHub Desktop入門

1. GitHubアカウントの作成

まずはGitHubのアカウントを作成します。

  • GitHubの公式サイト（https://github.com）にアクセス
  • 「Sign up」をクリック
  • 必要な情報を入力してアカウントを作成
  • メールアドレスの確認を完了

2. GitHub Desktopのインストール

GitHub Desktopをインストールしてバージョン管理を始めましょう。

  • GitHub Desktop公式サイト（https://desktop.github.com/）にアクセス
  • 「Download for Windows」をクリック
  • ダウンロードしたインストーラーを実行
  • GitHub Desktopを起動してGitHubアカウントでサインイン

3. リポジトリの作成と管理

プロジェクトの管理方法を学びます。

  • 新しいリポジトリの作成
    • File > New repository を選択
    • リポジトリ名と説明を入力
    • ローカルパスを設定
  • 既存のプロジェクトをGitHubに追加
    • File > Add local repository を選択
    • プロジェクトフォルダを選択

4. 基本的なGit操作

日常的に使用する操作を学びます。

  • 変更の確認（Changes）
    • 変更されたファイルの確認
    • 差分の確認
  • コミット（Commit）
    • 変更内容の説明を記入
    • コミットの実行
  • プッシュ（Push）
    • ローカルの変更をGitHubに反映
